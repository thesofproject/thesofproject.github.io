void * sof_ctx_alloc ( struct mod_alloc_ctx * ctx,
uint32_t flags,
size_t size,
size_t alignment )
inlinestatic

Allocate memory from a mod_alloc_ctx context.

When the context has a vregion, allocates from the vregion interim partition. Coherent memory is used when SOF_MEM_FLAG_COHERENT is set in flags. Falls back to sof_heap_alloc() otherwise.

Parameters
ctxAllocation context (heap + optional vregion).
flagsAllocation flags (SOF_MEM_FLAG_*).
sizeSize in bytes.
alignmentRequired alignment in bytes.
Returns
Pointer to allocated memory or NULL on failure.
