27/* Struct to define Mel filterback calculation. The filterbank data is compressed into
28 * a single vector from normal (half_fft_bins, mel_bins) size by storing only non-zero
29 * weights values.
30 *
31 * Triangles data Number triangles is mel_bins
32 * then for each triangle:
33 * index to next triangle 0, start fft_bin 1, length of this triangle 2,
34 * triangle weight values 3..N
35 */
