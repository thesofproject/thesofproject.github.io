Invalidate data cache lines in the specified memory region.

Parameters
addrStarting address of the memory region to invalidate.
sizeSize in bytes of the region to invalidate.

Discards cached data lines covering the address range so subsequent reads fetch fresh data directly from physical SRAM or DMA-updated memory.

size_t size )
inlinestatic

Write back (flush) modified data cache lines to memory.

Parameters
addrStarting address of the memory region to flush.
sizeSize in bytes of the region to flush.

Flushes dirty lines in the data cache covering the specified address range back to physical memory or SRAM. Mandatory before handing buffers over to hardware DMA or notifying peer cores / host.
