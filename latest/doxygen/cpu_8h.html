◆ PLATFORM_PRIMARY_CORE_ID

#define PLATFORM_PRIMARY_CORE_ID   0

Id of primary DSP core.

SOF IPC protocols make a distinction between primary and secondary cores. In Zephyr, primary core id concept is not present in public OS interface, but in implementation zero is the boot core (see z_smp_init() in Zephyr).
