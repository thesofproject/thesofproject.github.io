Returns new data blob handler.

Data blob handler has two modes of operation, single_blob == false stands for double blob mode that allow seamless configuration updates on the fly. In single_blob == true mode there is at most one blob allocated at one time and configuration update is not allowed if the component is active. The single blob mode should be used with components with very big configuration blobs to save DSP memory.

Parameters
devComponent device
single_blobSet true for single configuration blob operation
allocOptional blob memory allocator function pointer
freeOptional blob memory free function pointer
