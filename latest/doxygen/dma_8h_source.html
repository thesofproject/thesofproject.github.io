45/*
46 * There is significant overlap with SOF DMA interface and
47 * Zephyr zephyr/drivers/dma.h. Neither uses a unique namespace
48 * prefix, leading to at times confusing mix of DMA_ and dma_
49 * definitions, some coming from legacy SOF definitions, while
50 * some from Zephyr.
51 *
52 * Definitions in this file are used by following SOF code:
53 * - Some use of SOF DMA data types and definitions exists in
54 * generic application code (in IPC, host handling and a few other
55 * places). To support both XTOS and Zephyr builds, these
56 * definitions must be provided by the RTOS layer.
57 * - SOF builds where Zephyr is used but platform has not yet
58 * moved to native Zephyr drivers, so legacy/XTOS DMA are used.
59 * - Linking DMA resources to audio usages. Even SOF builds with
60 * native Zephyr build still use some SOF side DMA definitions
61 * to describe system DMA resources in terms of their capabilities
62 * for audio use. See sof/zephyr/lib/dma.c for most of this logic.
63 */
64
