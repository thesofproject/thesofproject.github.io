Detailed Description

Data Processing (DP) preemptible worker thread scheduler.

The Data Processing (DP) scheduler manages compute-intensive audio processing tasks by assigning a dedicated preemptible Zephyr thread to each SOF task.

Key Architectural Properties

  • Preemptible Execution: Each DP task executes in its own Zephyr thread at a priority lower than the hard real-time Low-Latency (LL) scheduler thread.
  • LL-Synchronized Evaluation: At the end of each Low-Latency tick, scheduler_dp_ll_tick() evaluates all queued DP tasks. If a task's sources contain enough audio data and its sinks have sufficient buffer space, its deadline is calculated and applied to the Zephyr thread via k_thread_absolute_deadline_set().
  • Task States & Return Values:
    • SOF_TASK_STATE_RESCHEDULE : Task completed a data chunk and requests rescheduling next period.
    • SOF_TASK_STATE_COMPLETED : Task completed processing and self-terminates until triggered again.
    • SOF_TASK_STATE_CANCEL : Task was cancelled and will be removed from the active queue.
