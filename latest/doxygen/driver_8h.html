◆ platform_ipc_init()

int platform_ipc_init ( struct ipc *  ipc)

Provides platform specific IPC initialization.

Parameters
ipcGlobal IPC context
Returns
0 if succeeded, error code otherwise.

This function must be implemented by the platform. It is called from the main IPC code, at the end of ipc_init().

If the platform requires any private data to be associated with the IPC context, it may allocate it here and attach to the global context using ipc_set_drvdata(). Other platform specific IPC functions, like ipc_platform_do_cmd(), may obtain it later from the context using ipc_get_drvdata().
