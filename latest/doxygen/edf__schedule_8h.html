Detailed Description

Legacy Earliest Deadline First (EDF) workqueue scheduler interface.

Deprecated
Deprecated for modern audio pipeline processing. In Zephyr-based builds, EDF is implemented as a delayed workqueue (edf_workq) retained for host IPC processing and legacy KPB draining tasks until migration. Audio pipeline components should use SOF_SCHEDULE_DP with native Zephyr thread deadlines or SOF_SCHEDULE_LL_TIMER / SOF_SCHEDULE_LL_DMA.
