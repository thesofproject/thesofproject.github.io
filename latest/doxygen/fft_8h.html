struct icomplex32 * output )

dft3_32() - Discrete Fourier Transform (DFT) for size 3.

Parameters
inputPointer to complex values input array, Q1.31.
outputPointer to complex values output array, Q1.31, scaled down by 1/3.

This function is useful for calculating some non power of two FFTs. E.g. the FFT for size 1536 is done with three 512 size FFTs and one 3 size DFT.

mod_fft_multi_plan_new() - Prepare FFT for 2^N size and some other FFT sizes

Parameters
modPointer to module
inbBuffer to use for complex input data
outbBuffer to use for complex output data
sizeSize of FFT as number of bins
bitsWorld length of FFT. Currently only 32 is supported.
Returns
Pointer to allocated FFT plan

This function does the preparations to calculate FFT. If the size is power of two the operation is similar to mod_fft_plan_new(). Some other FFT sizes like 1536 is supported by allocated multiple FFT plans and by wrapping all needed for similar usage as power of two size FFT.
