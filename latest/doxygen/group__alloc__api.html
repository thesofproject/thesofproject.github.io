◆ sof_sys_user_heap_get()

struct k_heap * sof_sys_user_heap_get ( void  )

Returns heap object to use for SOF heap allocations for audio application code.

The returned value may be NULL. This matches with semantics of sof_heap_alloc() that allows passing NULL as the 'heap'. In this case, the heap implementation will choose the heap to use.

The function should not be used for heap allocations for objects that are only used in SOF kernel space.

Note: audio modules should use mod_alloc() instead!
