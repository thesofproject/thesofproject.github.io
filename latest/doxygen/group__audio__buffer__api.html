Attach a new buffer at the beginning of a component buffer list.

Locking: Must be called with interrupts disabled (or userspace LL system mutex held). The caller takes care to protect list heads. "head" must really be the head of the list, not a list node within another buffer, as its cache is not synchronized and must not be embedded in an object using the coherent API.

Parameters
[in,out]bufferComponent buffer to attach.
[in,out]headList head to prepend buffer to.
[in]dirTraversal direction (PPL_DIR_DOWNSTREAM or PPL_DIR_UPSTREAM).
Returns
0 on success, or -EALREADY if the buffer is already linked in this direction.
