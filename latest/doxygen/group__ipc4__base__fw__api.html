IPC4 Base Firmware configuration and query parameter IDs.

Parameter IDs used with LARGE_CONFIG_GET and LARGE_CONFIG_SET commands addressed to the Base FW module instance (module ID 0, instance ID 0).

Enumerator
IPC4_DSP_PROPERTIES 

Retrieve firmware properties as TLV structure with typeof AdspProperties via LARGE_CONFIG_GET.

IPC4_DSP_RESOURCE_STATE 

Retrieve DSP resource state via LARGE_CONFIG_GET.

IPC4_RESERVED 

Reserved parameter identifier.

IPC4_NOTIFICATION_MASK 

Enable or disable asynchronous notifications.

Used in debug mode to prevent flooding the host with underrun notifications during breakpoints.

IPC4_ASTATE_TABLE 

Configure available power states according to the underlying platform.

Driver sends A-State table data right after Base FW is up.

IPC4_DMA_CONTROL 

Initialize or modify DMA gateway configuration outside stream lifetime.

Starts with struct ipc4_dma_control followed by optional gateway-specific data.
