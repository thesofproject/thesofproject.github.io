◆ ipc4_status

enum ipc4_status

IPC4 host-DSP status and error codes.

Returned in the lower 24 bits of the Primary reply DWORD (ipc4_message_reply::primary::r::status). Standard status codes are common across global and module commands, while values >= 100 convey subsystem-specific failures (module management, probes, gateways, and clocking).
