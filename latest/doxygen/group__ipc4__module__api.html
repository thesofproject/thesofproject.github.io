enum sof_ipc4_module_type

Module message command opcodes (5-bit opcode in Primary DWORD when msg_tgt == MODULE_MSG).

Enumerator
SOF_IPC4_MOD_INIT_INSTANCE 

Instantiate a new module object and attach to a pipeline.

SOF_IPC4_MOD_CONFIG_GET 

Retrieve a short 16-bit module parameter packed in header.

SOF_IPC4_MOD_CONFIG_SET 

Set a short 16-bit module parameter packed in header.

SOF_IPC4_MOD_LARGE_CONFIG_GET 

Retrieve multi-block configuration or state data from module.

SOF_IPC4_MOD_LARGE_CONFIG_SET 

Send multi-block configuration or filter coefficients to module.

SOF_IPC4_MOD_BIND 

Connect a source pin of this module to a destination pin.

SOF_IPC4_MOD_UNBIND 

Disconnect a runtime binding between two module instances.

SOF_IPC4_MOD_SET_DX 

Request core power state transition (D0/D3).

SOF_IPC4_MOD_SET_D0IX 

Request Base FW or module to enter low-power D0ix state.

SOF_IPC4_MOD_ENTER_MODULE_RESTORE 

Notify module to prepare for context restoration after wake.

SOF_IPC4_MOD_EXIT_MODULE_RESTORE 

Signal completion of module state restoration.

SOF_IPC4_MOD_DELETE_INSTANCE 

Destroy module instance and release allocated memory.
