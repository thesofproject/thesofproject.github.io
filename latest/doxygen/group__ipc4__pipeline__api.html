enum ipc4_pipeline_state

Pipeline operational state machine values.

Enumerator
SOF_IPC4_PIPELINE_STATE_INVALID 

Invalid or uninitialized pipeline state.

SOF_IPC4_PIPELINE_STATE_UNINITIALIZED 

Created but module initialization is incomplete.

SOF_IPC4_PIPELINE_STATE_RESET 

Reset state: buffers cleared, hardware inactive.

SOF_IPC4_PIPELINE_STATE_PAUSED 

Paused state: buffers pre-allocated, clocks armed.

SOF_IPC4_PIPELINE_STATE_RUNNING 

Running state: audio streaming actively scheduled.

SOF_IPC4_PIPELINE_STATE_EOS 

End Of Stream (EOS): draining final buffered audio.

SOF_IPC4_PIPELINE_STATE_ERROR_STOP 

Pipeline halted due to unrecoverable DSP error.

SOF_IPC4_PIPELINE_STATE_SAVED 

Pipeline context serialized to host memory for D3.
