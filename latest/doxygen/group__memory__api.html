Detailed Description

System heaps, Virtual Memory Heap (VMH), virtual regions, cold DRAM staging, and audio buffer allocators.

Note
Re-entrancy Contract: This API is NOT re-entrant. While runtime allocation and deallocation operations (vmh_alloc(), vmh_free()) synchronize internally via the heap mutex, heap lifecycle management operations (such as vmh_free_heap()) do not use mutual exclusion. It is assumed that only system management code performs heap lifecycle operations, and concurrent heap management with runtime allocations must be avoided.

Enumeration Type Documentation

◆ vregion_mem_type

enum vregion_mem_type

Memory allocation modes within a virtual memory region.

Distinguishes lifetime allocations (bound to pipeline topology, cannot be freed until teardown) from interim allocations (dynamically created and released during runtime operations).

Enumerator
VREGION_MEM_TYPE_INTERIM 

Interim allocation that can be freed dynamically (e.g.

large config set/get, controls).

VREGION_MEM_TYPE_LIFETIME 

Lifetime allocation that persists until region destruction (e.g.

topology, module instances).

VREGION_MEM_TYPE_INVALID 

Invalid memory type indicating initialization error or exhaustion.

Allocate runtime stream buffer with explicit alignment.

Runtime buffer allocator designed for audio stream buffers. Unlike rmalloc_align(), rballoc_align() actively prioritizes the Virtual Memory Heap (VMH / virtual_buffers_heap) when CONFIG_VIRTUAL_HEAP is enabled to preserve internal SRAM. Supports SOF_MEM_FLAG_L3 and SOF_MEM_FLAG_USER_SHARED_BUFFER. Respects SOF_MEM_FLAG_COHERENT for system and shared heaps, but note that the L3 heap path returns cached memory directly and does not support coherent uncached views.

Allocate memory block with explicit alignment and heap selection flags.

Core RTOS memory allocator. Evaluates flags to select the appropriate heap:

  • SOF_MEM_FLAG_L3: Allocates from the L3 IMR / external DRAM heap (cached only).
  • SOF_MEM_FLAG_USER_SHARED_BUFFER: Allocates from shared_buffer_heap.
  • Default: Allocates from system heap (sof_heap).

If SOF_MEM_FLAG_COHERENT is specified, returns an uncached (coherent) pointer. Otherwise, returns a cached pointer. When CONFIG_VIRTUAL_HEAP is enabled and system heap allocation fails, transparently attempts fallback allocation from the Virtual Memory Heap (VMH).

Parameters
[in]flagsMemory allocation flags, see SOF_MEM_FLAG_...
[in]bytesSize in bytes to allocate.
[in]alignmentRequired alignment in bytes (0 for default/natural alignment).
Returns
Pointer to the allocated memory block, or NULL on allocation failure.
