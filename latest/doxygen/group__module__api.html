◆ SOF_DEFINE_REG_UUID

#define SOF_DEFINE_REG_UUID (   name)    _DEF_UUID(#name, name##_uuid, SOF_REG_UUID(name))

Defines UUID sourced from the fixed SOF registry.

As for SOF_DEFINE_UUID(), but the ID value is sourced by name from the uuid-registry.txt file distributed with the source tree. The string name field will be identical with the name passed (which is passed as a symbol!), runtime symbol (e.g. the "uuid_name" argument to SOF_DEFINE_UUID()) will be the same, postfixed with a "_uuid".

Parameters
nameName of the UUID, must match an entry in uuid-registry.txt

enum sof_audio_buffer_state

Define states of an audio stream buffer connecting two components.

This enum represents the lifecycle of an audio stream, including its initialization, readiness, and end-of-stream handling. It is used to track and manage the state transitions of the stream during audio processing.

◆ source_set_alignment_constants()

int source_set_alignment_constants ( struct sof_source *  source,
const uint32_t  byte_align,
const uint32_t  frame_align_req 
)

Set byte and frame alignment constants for source stream.

Sets frame_align_shift and frame_align of stream according to byte_align and frame_align_req requirements. Once the channel number and frame size are determined, the frame_align and frame_align_shift are determined too. These features are used by audio_stream_get_avail_frames_aligned() to calculate available frames.

Note
This must be called in component prepare or param functions only once after channel count and frame size are known and before stream copying begins. If omitted or called late, aligned availability can evaluate to zero and no data will be copied.
Parameters
[in,out]sourcePointer to source structure.
[in]byte_alignProcessing byte alignment requirement.
[in]frame_align_reqProcessing frames alignment requirement.
Returns
0 on success, negative error code on failure.
