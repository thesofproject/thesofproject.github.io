Detailed Description

Digital Audio Interfaces (DAI), Direct Memory Access (DMA), and Power Management (PM) runtime.

SOF PM runtime specification mapping for Zephyr builds.

SOF DMA Drivers API specification (deprecated interface, to be replaced by Zephyr zephyr/drivers/dma.h interface).

Platform API specification.

DAI Drivers API specification.

This interface is considered deprecated and native Zephyr interfaces should be used instead.
