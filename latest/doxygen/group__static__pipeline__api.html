Detailed Description

The Static Audio Pipeline subsystem provides compile-time and runtime declarative topology construction for hostless, microcontroller, and standalone embedded platforms running Sound Open Firmware.

It allows platforms to construct complete SOF processing graphs (pipelines, modules, DAIs, intermediate buffers, routes, and kcontrols) directly at boot without requiring dynamic IPC topology commands from a host operating system.

int sof_static_pipeline_set_sample_rate ( uint32_t pipeline_id,
uint32_t rate )

Re-negotiate the stream sample rate for a specific static pipeline.

Re-negotiates the sample rate for the designated pipeline and its constituent components and buffers while the pipeline is in paused or stopped state. Validates that all constituent components support the requested rate according to their capability masks, reconfigures buffer period sizes, and propagates pipeline_params() and pipeline_prepare() through the pipeline graph.

Parameters
[in]pipeline_idTarget pipeline identifier.
[in]rateTarget sample rate in Hz (e.g. 16000, 44100, 48000, 96000).
Returns
0 on success, -EBUSY if the pipeline is currently active, -EINVAL if the rate is unsupported by component capabilities, or negative errno on failure.
