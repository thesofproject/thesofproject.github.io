IgoLibProcess() - Process audio stream.

Parameters
[in]handleiGo lib handle.
[in]ininput audio stream.
[in]refreference audio stream.
[out]outoutput audio stream.

This API is used to process audio stream. The default audio sample is 16bit. The sampling rate and sample number should be specified in IgoStreamData structure. If the channel number > 1 for IgoStreamData, the data should be interleaved sample by sample.

Note: IgoLibProcess supports 16k/48k 16bit data only by default. If other data format or sampling rate is required, please ask intelliGo for support.

Returns
iGo defined return value.
