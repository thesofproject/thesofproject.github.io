Sound Open Firmware C API & Architecture Reference

Overview

Sound Open Firmware (SOF) is an open-source, vendor-neutral audio Digital Signal Processing (DSP) firmware infrastructure, SDK, and real-time execution environment governed under the Linux Foundation.

SOF provides transparent, deterministic, low-latency audio processing for modern computing architectures ranging from client PCs and servers to embedded microcontrollers and IoT devices. It supports diverse hardware platforms including Intel (CAVS, ACE 1.x, ACE 2.x, ACE 3.x), AMD, NXP (i.MX8), MediaTek, Espressif (ESP32-P4), and PJRC (Teensy 4.1 / i.MX RT1062).

The firmware runs atop real-time operating systems (primarily Zephyr RTOS, with XTOS support on legacy platforms) and interfaces with host operating systems (Linux, ChromeOS, Android, Windows) via high-throughput Mailbox IPC protocols (IPC4 and IPC3) and DMA streaming windows.
