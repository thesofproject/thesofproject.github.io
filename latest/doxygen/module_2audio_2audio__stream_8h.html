enum sof_audio_buffer_state

Define states of an audio stream buffer connecting two components.

This enum represents the lifecycle of an audio stream, including its initialization, readiness, and end-of-stream handling. It is used to track and manage the state transitions of the stream during audio processing.

static int circ_buf_frames_without_wrap ( const void *  began,
const void *  end,
int  sample_bytes,
int  channels 
)
inlinestatic

Number of whole frames available before a circular buffer wraps.

Computes (end - began) / channels expressed in frames. The pointer distance is evaluated in bytes so the helper works for any sample width.

Parameters
begancurrent position in the circular buffer
endone past the last sample of the circular buffer
sample_bytessize of a single sample in bytes (2 for s16, 4 for s32)
channelsnumber of channels, i.e. samples per frame
Returns
number of frames that can be processed without wrapping
