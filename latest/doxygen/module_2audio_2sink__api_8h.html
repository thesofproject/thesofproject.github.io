Commits that the buffer previously obtained by get_buffer is filled with data and ready to be used.

Parameters
sinka handler to sink
commit_sizeamount of data that the caller declares as valid if commit_size is bigger than the amount of data obtained before by get_buffer(), only the amount obtained before will be committed. That means - if somebody obtained a buffer, filled it with data and wants to commit it in whole, it may simple call commit_buffer with commit_size==MAXINT
Returns
proper error code (0 on success)

Get a circular buffer to operate on (to write).

Retrieves a fragment of circular data to be used by the caller After calling get_buffer, the space for data is guaranteed to be available for exclusive use on the caller core through provided pointer if the provided pointers are cached, it is guaranteed that the caller may safely use it without any additional cache operations The caller MUST take care of data circularity based on provided pointers

Parameters
sinka handler to sink
[in]req_sizerequested size of space
[out]data_ptra pointer to the space will be provided there
[out]buffer_startpointer to circular buffer start
[out]buffer_sizesize of circular buffer
Return values
-ENODATAif req_size is bigger than free space

◆ sink_set_alignment_constants()

int sink_set_alignment_constants ( struct sof_sink *  sink,
const uint32_t  byte_align,
const uint32_t  frame_align_req 
)

Set frame_align_shift and frame_align of stream according to byte_align and frame_align_req alignment requirement.

Once the channel number,frame size are determined, the frame_align and frame_align_shift are determined too. these two feature will be used in audio_stream_get_avail_frames_aligned to calculate the available frames. it should be called in component prepare or param functions only once before stream copy. if someone forgets to call this first, there would be unexampled error such as nothing is copied at all.

Parameters
sinka handler to sink
byte_alignProcessing byte alignment requirement.
frame_align_reqProcessing frames alignment requirement.
Returns
0 if success
