Typedef Documentation

◆ PinEndpoint

typedef void* intel_adsp::PinEndpoint

defines type of the pin endpoint.

A custom module is required to provide to the ADSP System some PinEndpoint value arrays. Arrays length shall be as long as it has input and output pins. (ref ProcessingModuleFactoryInterface::Create()).
