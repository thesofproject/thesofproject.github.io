AdspErrorCode native_system_service_get_interface_versioned ( enum interface_id id,
uint32_t version,

Retrieve a versioned system service interface.

Parameters
idService interface identifier.
versionRequested interface version.
ifaceLocation for the returned interface pointer.
Returns
ADSP_INVALID_PARAMETERS for invalid arguments. If the requested service has no provider, return ADSP_SERVICE_UNAVAILABLE without checking its version. A provider returns ADSP_SERVICE_VERSION_UNAVAILABLE when it exists but does not support the requested version.
