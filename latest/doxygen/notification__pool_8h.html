struct ipc_msg * ipc_notification_pool_get ( size_t size)

Retrieves an IPC notification message from the pool.

This function retrieves and returns an IPC notification message of the specified size from the notification pool. The size of the message is limited by the maximum size available in the pool.

Parameters
sizeThe size of the IPC message to retrieve.
Returns
A pointer to the retrieved IPC message, or NULL if retrieval fails.
