typedef int(* pcm_converter_func) (const struct cir_buf_source *source, uint32_t src_channels, struct cir_buf_sink *sink, uint32_t sink_channels, size_t source_samples, uint32_t chmap)

PCM conversion function interface for data in circular buffer.

Parameters
sourcecircular-buffer source descriptor, read pointer is not modified
src_channelsnumber of channels in the source stream
sinkcircular-buffer sink descriptor, write pointer is not modified
sink_channelsnumber of channels in the sink stream
source_samplesnumber of samples to convert, for remapping – number of source samples
chmapchannel map for remapping, ignored by non-remapping conversion func
Returns
error code or number of processed samples (source samples in case of remapping).
