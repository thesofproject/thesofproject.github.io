34/* Defines maximum amount of memory block allocators in one heap
35 * since minimum realistic block should be cache line size
36 * and block sizes in allocator must be powers of 2
37 * so logically it gives limited block sizes
38 * eg allocator of block size 64 128 256 512 2048 4096 1024 8192
39 * would end up in 8 allocators.
40 * It is expected that allocations bigger than that would
41 * either be spanned on specifically configured heap or have
42 * individual configs with bigger block sizes.
43 */
44#define MAX_MEMORY_ALLOCATORS_COUNT 10
45
