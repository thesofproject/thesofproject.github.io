119/*
120 * SOF-specific mechanism to allow building SOF with user-space
121 * support enabled in Zephyr, but not including all syscall
122 * interfaces in the SOF binary. Thee downside is we cannot
123 * use the zephyr/syscalls/sof_dma.h boilerplate that is autogenerated
124 * but instead need a manual wrapper that is below here.
125 *
126 * This can be removed if DMA is used in all SOF user-space builds.
127 */
