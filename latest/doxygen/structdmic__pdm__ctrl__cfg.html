Detailed Description

Pulse Density Modulation (PDM) controller configuration for DMIC.

Defines the configuration parameters for the PDM control of the DMIC module, including CIC decimation filter, microphone gain/control, SoundWire pin mapping, and dual FIR filter cascades.
