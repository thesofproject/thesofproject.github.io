size_t intel_adsp::OutputStreamBuffer::size

size indicator about the data in the stream buffer

  • When read, it indicates the size of available room in the stream buffer
  • When written, it reports the size of data which has actually be produced into the buffer during the buffer processing (can be less than the given available room size)
