enum intel_adsp::ProcessingMode::Enum

enumeration values of processing mode

Enumerator
NORMAL 

Indicates that module is expected to apply its custom processing on signal.

BYPASS 

Indicates that module is expected to not apply its custom processing on signal. The module is expected to forward as far as possible the input signals unmodified with respect of the signal continuity at the mode transition.
