Detailed Description

Standard 64-bit IPC4 message request envelope.

Used for all host-to-DSP command requests. When msg_tgt is SOF_IPC4_MESSAGE_TARGET_FW_GEN_MSG, the type field is one of ipc4_message_type. When msg_tgt is SOF_IPC4_MESSAGE_TARGET_MODULE_MSG, type is one of sof_ipc4_module_type.
