Detailed Description

SW Driver sends Bind IPC message to connect two module instances together creating data processing path between them.

Unbind IPC message is sent to destroy a connection between two module instances (belonging to different pipelines) previously created with Bind call.

NOTE: when both module instances are parts of the same pipeline Unbind IPC would be ignored by FW since FW does not support changing internal topology of pipeline during run-time. The only way to change pipeline topology is to delete the whole pipeline and create it in modified form.
