Detailed Description

Pipeline state transition command structure (SOF_IPC4_GLB_SET_PIPELINE_STATE).

Directs one or more pipelines to transition their operational state (e.g. RESET -> PAUSED -> RUNNING). For multi-pipeline audio chains, drivers must start pipelines in reverse topological order (from output gateway backwards to input) to prevent intermediate buffer overruns.
