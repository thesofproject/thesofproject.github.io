Detailed Description

Generic message header.

Generic raw 64-bit IPC4 message header registers.

IPC MAJOR 3 version. All IPC3 messages use this header as abstraction to platform specific calls.

All IPC4 messages are passed across the mailbox as a pair of 32-bit registers (Primary DWORD + Extension DWORD).
