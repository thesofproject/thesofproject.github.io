uint8_t ipc_user::init_drv_data[160]

User-accessible copy of comp_driver + tr_ctx for create().

The comp_driver and tr_ctx structs reside in kernel memory (.rodata/.data) which is not user-readable. The kernel handler copies them here before forwarding to the user thread. Size verified by BUILD_ASSERT in handler-user.c.
