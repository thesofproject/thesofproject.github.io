Detailed Description

Module TLV parameters container - used for both config types.

For example if one want to set the sample_rate to 16 [kHz] and this parameter was assigned to id 0x01, its max size is four bytes then the configuration filed should look like this (note little-endian format): 0x01 0x00 0x00 0x00, 0x0C 0x00 0x00 0x00, 0x10 0x00 0x00 0x00.
