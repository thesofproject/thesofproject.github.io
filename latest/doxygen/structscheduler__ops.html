Detailed Description

Scheduler operations interface table.

Schedulers implement this interface to plug into the unified SOF scheduling abstraction. Almost all schedule operations must return 0 for success and negative values for errors. Only the optional scheduler_free operation returns void.

◆ schedule_task

int(* scheduler_ops::schedule_task) (void *data, struct task *task, uint64_t start, uint64_t period)

Schedule a task with the given timing parameters.

Parameters
[in,out]dataPrivate state of the selected scheduler.
[in,out]taskTask descriptor to be scheduled.
[in]startStart timing parameter (scheduler-specific, e.g. start delay or absolute tick for LL).
[in]periodRepetition period in microseconds for periodic schedulers (such as LL, where 0 denotes one-shot). Schedulers such as DP and TWB ignore this parameter as rescheduling is governed by the task's returned execution state.
Returns
0 on success, negative error code on failure.

This operation is mandatory.
