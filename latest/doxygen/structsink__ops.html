int(* sink_ops::on_audio_format_set) (struct sof_sink *sink)

OPTIONAL: Notification to the sink implementation about changes in audio format.

Once any of *audio_stream_params elements changes, the implementation of sink may need to perform some extra operations. This callback will be called immediately after any change

Return values
0if success, negative if new parameters are not supported
