Detailed Description

Complete map for each channel of a multichannel stream.

num_ch_map Specifies number of items in the ch_map. More than one transformation per a single channel is allowed (in case multiple external entities are transformed). A channel may be skipped in the transformation list, then it is filled with 0's by the transformation function.
