Detailed Description

This is a struct that aggregates vmh_block_bundle_descriptor to create one cfg that can be passed to heap initiation.

Provided config size must be physical page aligned so it will not overlap in physical space with other heaps during mapping. So every block has to have its overall size aligned to CONFIG_MM_DRV_PAGE_SIZE
