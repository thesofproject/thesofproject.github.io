Parameters

computes COS(THETA) + j*SIN(THETA) using CORDIC algorithm approximation and returns the complex result. THETA values must be in the range [-2*pi, 2*pi). sofm_atan2_32b() - Four-quadrant arctangent using degree-9 Remez minimax polynomial

Parameters
yImaginary component (sine) in Q1.31 format.
xReal component (cosine) in Q1.31 format.
Returns
Angle in Q3.29 radians, range [-pi, +pi].

Uses the Horner-form polynomial: atan(z) = z * (C0 + z^2 * (C1 + z^2 * (C2 + z^2 * (C3 + z^2 * C4))))

with Remez minimax coefficients on [0, 1]. Maximum error ~0.001 degrees (1.94e-5 radians).
