Detailed Description

Thread With Budget (TWB) scheduler interface and cycle accounting.

The Thread With Budget (TWB) scheduler creates a separate preemptible Zephyr thread for each SOF task that has a pre-allocated MCPS budget renewed with every system tick.

Key Architectural Properties

  • Dynamic Priority Switching: The TWB scheduler assigns either MEDIUM_PRIORITY or LOW_PRIORITY to the task thread based on the budget remaining in the current system tick.
  • Opportunistic Execution: If there is no higher-priority ready task, the thread can continue executing at low priority even after its budget is exhausted.
  • Cycle & Tick Accounting:
    • cycles_granted: Budget in Zephyr system clock ticks per period (passed to k_thread_time_slice_set()).
    • cycles_consumed: Actual execution time consumed during the current period, measured in DSP hardware clock cycles.
  • Budget Exhaustion & Replenishment:
    • When consumed cycles exceed granted cycles, Zephyr time slicing triggers scheduler_twb_task_cb(), which lowers thread priority to CONFIG_TWB_THREAD_LOW_PRIORITY.
    • On the next Low-Latency tick (scheduler_twb_ll_tick()), consumed cycles are reset to 0, and the original thread priority is restored. Unused budget is not carried over.
