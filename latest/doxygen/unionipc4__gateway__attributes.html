Detailed Description

Gateway configuration BLOB structure.

Attributes are usually provided along with the gateway configuration BLOB when the FW is requested to instantiate that gateway.

There are flags which requests FW to allocate gateway related data (buffers and other items used while transferring data, like linked list) to be allocated from a special memory area, e.g low power memory.
