8/*
9 * A set of functions that allows implement a watchdog protection for ll scheduler tasks. The
10 * watchdog_enable function is called after creating a ll thread for specified core. Its task is to
11 * start the watchdog for a given core. When all tasks are finished, function watchdog_disable will
12 * be called before stopping the thread. It should stop the watchdog on the given core.
13 * Periodically, after each tick has been handled, the watchdog counter is reseted by calling
14 * watchdog_feed.
15 */
